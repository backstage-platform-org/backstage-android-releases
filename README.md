# Backstage for Android

Downloads of the Backstage Android app. Backstage runs a festival's tickets, gates,
venue map, crew and incidents in one system: <https://backstage.observer>

This repository holds only the app's releases. It contains no source code.

## Install

1. On your Android phone, download the latest
   [backstage.apk](https://github.com/backstage-platform-org/backstage-android-releases/releases/latest/download/backstage.apk).
2. Open the downloaded file. Android asks once whether your browser may install apps;
   allow it for this install.
3. If Play Protect offers to scan the app, let it.

The app needs Android 8.0 or newer and a network connection.

## Update

Download the latest file and open it. It installs over the app you have and keeps
you signed in.
